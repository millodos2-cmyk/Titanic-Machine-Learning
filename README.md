# Titanic Machine Learning

## Descripción del proyecto

Proyecto de análisis de datos y Machine Learning basado en el conjunto de datos del Titanic. El objetivo es explorar los datos de los pasajeros y desarrollar un modelo de clasificación utilizando el algoritmo K-Nearest Neighbors (KNN) para predecir la supervivencia.

## Contenido del repositorio

- **`KNN ejercicio.ipynb`**: notebook con el desarrollo de la práctica, el análisis de los datos y la implementación del modelo KNN.
- **`train.csv`**: conjunto de datos de entrenamiento.
- **`test.csv`**: conjunto de datos de prueba.
- **`gender_submission.csv`**: archivo de referencia con predicciones de supervivencia basadas en el género.

## Herramientas utilizadas

- Python
- Jupyter Notebook
- Pandas
- Scikit-learn
- Machine Learning (KNN)

## Objetivo de aprendizaje

Practicar el análisis y la preparación de datos, la aplicación de algoritmos de clasificación y la evaluación de modelos de Machine Learning.
